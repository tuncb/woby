Try the flow:
Fast, local editing

F2 or Rename turns the row label into a text field. The Name field in Properties is also editable. Enter or a click outside applies a valid name. Escape cancels.

One clear reset

The reset arrow and “Restore original name” do the same action. Show the exact original name below the field. Disable reset when that name is in use.

Safe to change

Apply each rename or reset as one Undo step. Save custom names in the .woby scene. Keep the source filename, path, and imported object names intact.

Predictable scope

Change one selected model, imported group, or part. Reset only that item. Keep child names as they are. With multiple items selected, ask the user to select one item.

Interaction and implementation details
  • Keep double-click for model expansion. Use F2 only when the model tree has focus and one item is selected. Do not take this key from another editor.
  • Select the full label when inline editing starts. Keep the eye control and expand arrow separate from the text field. Keep the same tree order, selection, and expansion state after each change.
  • Trim outer spaces. Reject an empty or whitespace-only name. Enter keeps the invalid field open with a message; a click outside cancels the invalid edit. Support Unicode and duplicate names. Use the parent model and source path to identify duplicates. Show long names in full in a tooltip.
  • For a model, the original name is its source filename, including the extension. For imported groups and parts, it is the label supplied on import. Retain the existing fallback label for an unnamed part.
  • A name equal to the original clears the custom name. Rename and reset share the same operation boundary. A no-op does not add an Undo step or mark the scene as changed.
  • Update the tree, Properties, analysis source lists, and annotation target labels together. The object identity stays the same. Existing analysis results remain valid.
  • Store a separate custom-name value in UiState-owned model, group, or part state. Keep imported identity separate. Apply changes through ui_operations; map custom names to .woby save/load and scene history. Old scenes use their original names. Saved views do not restore names.
  • Keep edit buffers, focus, and context-menu position in UI runtime state. Invalidate label-derived caches after a committed name change. Cancel an edit if its object is removed or the scene is replaced.
  • This prototype covers one model and its parts. Imported groups use the same interaction. Multi-selection and scene-file persistence are specified here but are not simulated.
