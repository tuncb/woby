What changed

  • AVX2 is the x64 minimum for woby targets. Apple ARM64 builds target M1 and use NEON.
  • Bounds use explicit compare-and-select reductions. They retain the first value on equal or unordered comparisons. This preserves signed-zero and NaN behavior.
  • Original-coordinate bounds select position storage once. Index checks remain in the loop. This removes a function call and repeated SIMD register spills for each corner.
  • Coordinate rebasing uses contiguous vector loads and subtracts. Its loop stays outside the large importer function.
  • Mesh and group radius rules, finite-coordinate validation, source IDs, seams, progress callbacks, and worker cancellation remain covered by tests.
  • Integer bit checks normalize signed zero in analysis and scene hashes. This fixes a regression exposed by the AVX2 build.

AVX-512 and Apple M1

WOBY_ENABLE_AVX512_REBASE=ON adds a separate AVX-512 translation unit for coordinate rebasing. CPU feature and OS register-state checks guard each dispatch. The option is off by default. The measured build included it, but this Ryzen CPU selected AVX2.

AVX-512 compilation and instruction inspection passed. Native AVX-512 execution was not available. The NEON headers passed an ARM64 Clang compile with warnings treated as errors. That check used an ARM64 Windows target; a native macOS build and M1 timing remain open.

The report supports faster bounds selection and access. It does not establish a benefit from 512-bit vectors on this workload. See the MSVC ISA option reference and the Arm NEON intrinsic reference.

Validation

The Release application and tests build without warnings. All 82 default test groups and all 8 slow tests pass. Affected geometry tests were repeated after the final code changes. New cases cover storage modes, primitive ranges, invalid indices, signed zero, NaNs, subnormal hashes, vector tails, progress, and radius rules.

A small compiler check reproduces the hash issue: MSVC 19.51 with /O2 /arch:AVX2 removes the floating-point zero selection before a bit cast. The SSE2 build retains it. Integer normalization retains the check in both builds. The source and assembly listings are in the archive.

Method and reproduction

Input: 7,108,991,827 bytes; 75,771,986 triangles; 38,414,391 render vertices; 37,890,645 source positions. Each run uses a fresh process and 16 parser workers. The runner warms the input and rotates build order. No build or test job runs during measurement. Geometry validation occurs after the timed preparation phases.

The original executables were saved from revision 039eed0ebab1 before changes. The compiler-only control applies AVX2 to the six instrumented source units and harness; its common libraries retain the original ISA. The final build applies the new x64 baseline to woby targets. The archive includes an earlier three-way comparison; the tables above use only final-measurements.json.
