Two repeats per event group. IPC = retired instructions / cycles. L2 miss share uses cacheable data requests. DTLB walk share uses L1 DTLB misses. These are different denominators, from separate sampled captures.

Work per shifted-pair query

Means combine both directions. Large meshes select every 100th 128-face batch against the full target trees. Histogram and second-stride checks are retained in the data. Maximum visits are observed maxima, not percentile estimates.

Counter data cover demand cache fills, L2 requests, prefetches, branches, TLB walks, dispatch stalls, and divide/SSE events. IBS, L3 PMCs, and memory-controller counters are unavailable on this host.

Quality: one isolated code change

A separate experimental build changes only the maximum-of-three expression in the degeneracy check. Bus uses four alternating runs per variant after compiler activity stops. Large models have one experimental run; they need more repeats before a production change.
