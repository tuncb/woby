OBJ loading without the mapping fallback

Bennu imports 22.8% faster. The application uses one mapping pipeline for faces, lines, points, clouds, and freeforms.

The checkpoint is commit 6d712bb. The new version removes the fused mapper, the eligibility guards, and the mapper selection option from production source. Global first-use IDs, triangle order, attributes, and group order are preserved.

Memory and implementation

Bennu's primary lookup grows from 34.08 to 102.24 MiB. The common path releases 766.76 MiB of parsed triangle records before allocating render vertices. The whole-process peak stays near 2,211 MiB because parsing sets the peak. Retained buffers stay at 715.65 MiB.

  • Faces resolve first. Lines and points then share the same primary table, seam table, and global ID counter. New primitive-only IDs carry an internal normal flag, so they do not trigger replacement of authored face normals.
  • Clouds fill source-order IDs and vertices directly, with up to eight workers. They allocate no ID lookup. The two-million-position cloud lowers peak commit by 7.27 MiB.
  • Freeform evaluation appends its geometry after the common primitive pass. Freeform-only input allocates no unused OBJ lookup table.
  • Sparse inputs use the common 12-byte primary entry per source position. No sparse selection rule was added.
  • The face lookup stays directly in the corner loop. Extracting it into a shared helper slowed models with many seams by about 4–5% on MSVC. A branch-only rewrite did not recover the loss; keeping the hot face block inline recovered Powerplant and reduced San Miguel's delta.
  • Historical benchmark sources are frozen under experiments/obj-mapping-reference. They are excluded from the production loader. The production link map contains the common builder and no old lookup-table symbols.

Correctness and build checks

All final CPU fingerprints match the checkpoint. The 124-file fixture set covers mixed attributes, UV overflow, repeated references, duplicate coordinates, sparse positions, clouds, and freeforms, in eager and deferred modes.
