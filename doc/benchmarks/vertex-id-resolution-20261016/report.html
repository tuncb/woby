Implementation

  1. Divide source positions into at most eight ranges. One worker owns each range and discovers its keys in original corner order. The lowest and highest position IDs in each 1,024-corner block let workers skip unrelated input.
  2. Store each key’s first corner in the output index buffer. A bit set marks first uses. Count these bits in parallel, then calculate the ordered block offsets. Assign IDs in the original first-use order.
  3. Keep final IDs in first-corner slots while other workers fill repeated indices. This prevents a write/read race and avoids a full temporary corner map. Merge seams in original ID order.
  4. Keep the serial path below 1,048,576 corners or 65,536 source positions, and when fewer than four workers are available. Use the existing shared helper limit. Progress callbacks run only on the caller. Errors stop work and join helpers.

  • All measured imports preserve the complete geometry and colour fingerprints. Replay compares every index, primary entry, seam and group against the serial reference. Experiments

The first version scanned all corners once per position range. Its two-run replay improved from about 2.04 to 1.80 seconds. Block bounds reduced this to about 1.30 seconds. Tests with 4,096, 1,024 and 256 corners per block selected 1,024 as a balance between scan traffic and block overhead. The final version also uses SIMD to count first uses and removes the last full index pass.

The first integrated BearTrap survey was inconclusive: full-import medians were 9.347 and 9.532 seconds, despite faster resolution. These samples are retained in the results. The final comparison above uses the later implementation, five import pairs and ten viewer pairs. The preliminary results for the other four models are also retained.

Repeat the comparison

Build both revisions with the vs2026-vcpkg preset in Release mode. Enable WOBY_BUILD_OBJ_PROFILE and WOBY_BUILD_RAPIDOBJ_PROTOTYPE_BENCHMARK. Preserve the baseline binary directory.

uv run experiments/obj-profile/annotation_compare.py BASELINE_BIN CANDIDATE_BIN D:/temp/obj_tests/20190810_BearTrap_Ground_Model.obj --output NEW_DIRECTORY --rounds 5 --modes import,viewer

Use a separate directory with --rounds 1 --modes traced-viewer for phase diagnostics. The runner warms the input, alternates build order, and rejects samples that overlap another compiler, test runner or viewer. Fingerprint checks run outside the timers. The optional WOBY_BUILD_ID_RESOLUTION replay checks the complete resolver output.

The second viewer campaign exposed a process-ownership race in the runner. The completed capture proved that a reported competitor was the measured viewer itself. The original sample is retained; its automatic retry is excluded from the summary. The runner now checks the completed capture’s process IDs. The original records and the correction are preserved.

Scope: five OBJ models, one Windows laptop, warm input and Release builds. No cold-storage or other-machine gain is claimed.
