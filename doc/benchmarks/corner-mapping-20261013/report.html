Method and limits

Each measurement uses a fresh Release process. The input file is read before each process to warm the file cache. Runs are sequential. Configuration order rotates each round.

Mapping total = mesh_allocation + corner_mapping. Resolve, input release, vertex allocation, position mapping, and gather phases are children of corner_mapping. Their times are shown for inspection. They are not added to the total again.

CPU load is the wall time of cpu_import. Process wall time also includes geometry checks and process start and exit. This report makes no claim about first-frame time, GPU upload, or full feature readiness.

Byte counters describe array capacities or logical data accesses in the measured code. They do not measure cache traffic, physical memory bandwidth, or page residency. Initialization bytes count the array elements initialized by the operation; initializers can set default values as well as zero. A counter marked upper_bound is an upper bound. Missing counters are not treated as zero.

Primary entries and seam keys are temporary lookup arrays. The split variants retain ordered keys for every unique vertex. Compact variants use source-position slots for primary keys and full keys only for seam vertices. They allocate no second corner array. Source-order gathering writes to the original first-use render IDs. Gather worker counts change gathering; resolution remains serial.

Compact primary entries use 12 bytes per source position. The baseline primary map uses 4 bytes per source position. The extra 8 bytes per source position can increase resident memory when many source positions are unused. Ordered keys are removed for primary vertices, but this saving depends on how many positions the model uses.

For mixed faces and explicit line or point records, the split path allocates the exact face vertex count before gathering. The vertex array can grow when later primitives add vertices. Early triangle input release is skipped. A path with no triangle indices keeps the existing direct table and vertex reservation.

Early input release depends on parsed shapes having no explicit line or point records. Freeform patches can still be appended later. The recorded triangle_only flag describes this parsed-shape check; it does not require the final model to contain only triangles.
