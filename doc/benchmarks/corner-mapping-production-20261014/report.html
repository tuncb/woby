Every run has the same ordered-mesh fingerprint for its model. The fingerprint includes render vertices, ordered triangle/line/point indices, source coordinates and indices, position maps, origin, group ranges, and UV flags. Unit tests also cover eager and deferred state, identity positions, sparse sources, mixed primitives, freeforms, parallel output, worker limits, and cancellation.

Selection and fallback

  • Use the compact staged path for attribute-bearing triangles. Source-position slots store the primary normal/UV key and render ID. Only seam vertices need full keys and hash lookup.
  • Keep the original mapper for position-only files, explicit line or point records, freeform patches, and source-position counts above twice the total corner-reference count. The sparse rule avoids a large 12-byte primary table when the 4-byte lookup and bounded full-key storage are smaller.
  • Bennu uses the position-only path. Its new-mode timings describe that same algorithm, with normal run-to-run variation.
  • Keep float32 GPU vertices and the existing upload path. The packed normals/UVs and binary import cache commit is excluded from this implementation.

Buffers and passes

The staged path allocates one 12-byte primary record per source position, 16-byte seam records, and 4-byte hash buckets. It writes render indices, then releases parser triangle records before allocating the final vertex array. It checks position identity, builds the source map when required, and gathers primary and seam attributes in separate passes. Workers write to disjoint first-use IDs and join before publication. Only the caller reports progress or polls cancellation.

The final vertex array has the exact resolved length. This removes growth reserve when seams push the vertex count above the source-position estimate. The CSV records allocation, resolution, release, mapping, and gather times, table capacities, retained arrays, and process peaks. Released-triangle bytes describe logical array payloads. Worker stacks and allocator/driver overhead are outside exact array capacities. Lower retained memory does not imply a lower parser peak.

Build and checks

The default application enables this path. No experimental build option is required. The reference switch exists in the prototype benchmark API.
