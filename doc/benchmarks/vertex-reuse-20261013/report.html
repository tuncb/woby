What the result means

For a well-connected triangle surface, a complete vertex can serve about six corners. At six references, indexed storage uses 28 bytes per triangle rather than 96: a 70.83% saving. UV seams and normal splits reduce reuse.

The mapping redesign keeps these same vertex and index counts. It makes the conversion faster and reduces temporary CPU storage; vertex reuse already existed in the original importer.

Indexing is beneficial when average reuse exceeds 32/28 = 1.143 references per vertex. A mesh with no shared complete vertices grows by 12.5% if we add uint32 indices.

Methods used for large meshes

  1. Index complete vertex records and improve locality. meshoptimizer provides remapping, triangle ordering for vertex reuse, and vertex fetch ordering. Its implementation uses contiguous hash buckets with quadratic probing. Our tuple-first mapping avoids expanding a large OBJ into 3T full vertex records before deduplication. Library pipeline · Index generator
  2. Pack attributes more tightly. Quantized normals and UVs reduce resident GPU memory. glTF defines integer vertex formats for this purpose. A candidate float32 position + packed 4-byte normal + 4-byte UV uses 20 bytes per vertex before any backend padding. This is a proposal, not measured here. UV range and precision must be checked. glTF quantization
  3. Compress a prepared binary cache. meshopt codecs reduce disk and transfer size, then decode to the normal vertex/index buffers. This alone does not shrink resident GPU buffers. The glTF extension supports independent compressed buffer views. glTF meshopt compression
  4. Partition large models. Smaller draws can use 16-bit local indices, at a cost in boundary vertex copies and draw bookkeeping. Meshlets use local triangle indices and global vertex references, and support fine-grained culling. NVIDIA reports a large-scan example, but its timing is not a prediction for woby. NVIDIA professional graphics
  5. Stream clusters and select detail. Nanite builds hierarchical triangle clusters and loads visible detail on demand. This makes resident memory depend on the visible working set. It requires a wider rendering design. Nanite · AMD GPU meshlet decompression
  6. Limit concurrent work by memory. The meshoptimizer author's billion-triangle studies describe avoiding redundant copies, processing only needed attributes, and scheduling large meshes with memory limits. 2025 study · 2026 follow-up

For woby, the next small experiments are packed GPU normals/UVs and a reusable binary import cache. Triangle reordering needs a mapping back to source triangle IDs and must preserve group/material ranges. The sparse-position fallback addresses temporary mapping cost; it does not add vertex reuse.
